# Security Policy

## Reporting a vulnerability

Use [GitHub Private Vulnerability Reporting](https://github.com/cixiangtao/skills/security/advisories/new) for suspected vulnerabilities in a published skill, validation script, installation instruction, or documented workflow.

Do not disclose exploit details, credentials, private repository data, personal paths, or unsafe command sequences in a public issue. Include the affected skill or script, the security boundary that can be crossed, reproduction conditions, impact, and a safe mitigation when known.

Ordinary documentation errors and non-sensitive behavior bugs belong in GitHub Issues. Reports are handled on a best-effort basis; the repository does not promise a fixed response or resolution time.
