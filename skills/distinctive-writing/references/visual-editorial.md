# 图文编辑系统

在文章包含配图计划、需要生成图片、已有图片需要编排，或用户强调阅读体验时阅读本文件。

## 图片不是一种统一材料

先判断图片的工作，再决定形式。

| 角色 | 适合形式                             | 核心问题                         |
| ---- | ------------------------------------ | -------------------------------- |
| 证据 | 原始截图、实拍照片、数据图、文献局部 | 它能证明什么，来源是否可靠？     |
| 解释 | 流程图、结构图、对比图、标注图       | 它是否比一段文字更快讲清关系？   |
| 节奏 | 相关场景、局部细节、章节插画         | 删除它后是否会让阅读明显疲劳？   |
| 情绪 | 漫画、表情、视觉隐喻                 | 它传达了文字不便直接说出的什么？ |
| 记忆 | 核心概念海报、总结图、贯穿意象       | 脱离正文后是否仍能准确表达观点？ |

一张图可以承担两个角色，但不要声称它什么都能做。

## 推荐顺序

1. 列出文章脊柱与主要章节。
2. 标记读者会质疑、难理解、阅读疲劳或情绪转折的位置。
3. 为这些位置选择图片角色。
4. 再决定使用现有素材、现场截图、手工图表、图解还是生成图。
5. 写完正文后复查位置和必要性，而不是按固定字数机械插图。

通常一篇中等长度文章需要少量强图，不需要每隔三段塞一张库存照片。数量由内容决定。

## 证据边界

- 生成图不能作为新闻、事件、产品界面、实验结果或人物经历的证据。
- 数据图必须来自真实数据；坐标、单位、范围和时间不得为了视觉效果被隐藏。
- 截图应保留理解所需的上下文，并处理个人信息、令牌、地址和敏感内容。
- 对经过裁剪、拼接、标注或重绘的素材明确说明。
- 不能确认授权时，提供素材方向或生成替代方案，不把网络图片默认当作可自由使用。

## 视觉一致性

同一篇文章先确定简单的视觉语法：

- 主色与强调色；
- 摄影、线稿、拼贴、漫画或信息图中的主要形式；
- 圆角、边框、阴影、标注箭头和字体的统一规则；
- 横版封面、正文宽图、方形传播图各自的比例；
- 情绪是冷静、荒诞、温暖还是锋利。

证据截图不必强行套艺术滤镜。视觉一致性不能损害真实性和可读性。

## 生成图片

只有用户明确希望得到实际图片，并且图像工具可用时才生成。生成前提供或内部明确：

- 用途与插入位置；
- 画面主体与动作；
- 视觉隐喻；
- 构图、视角和留白；
- 色彩与材质；
- 画幅比例和目标尺寸；
- 必须出现与必须避免的元素；
- 是否需要文字。

除非生成工具能够可靠处理指定文字，否则让画面预留排版区域，文字在后续设计中添加。不要让模型自由发明品牌标志、产品界面、数据或新闻现场。

## 图文清单格式

为每张图提供足以执行的信息：

```markdown
### 图 2：全局状态的行李寄存处

- 位置：解释第三类状态之后
- 角色：解释 + 记忆
- 画面：不同尺寸的行李全部塞进一个写着 STORE 的狭小寄存柜，取件队伍越来越长
- 形式：简洁 editorial illustration，非真实产品界面
- 构图：横版 16:9，主体偏左，右侧留出标题区域
- 图注：东西都能放进去，不等于以后还找得到。
- 替代文本：多个不同用途的状态被塞进同一全局存储，形成拥堵和依赖。
- 来源或生成说明：AI 生成概念插画；不作为技术证据
```

## 图注与替代文本

图注解释“为什么看这张图”，可以补充时间、数据口径、作者判断或笑点。不要只写“示意图”。

替代文本描述读者为了理解文章所需的视觉信息：

- 简洁说明主体、关系和关键文字；
- 不重复相邻正文已经完整表达的内容；
- 纯装饰图使用空替代文本或在交付说明中标记为装饰；
- 图表说明趋势、比较和异常点，而不逐像素描述。

## 最终检查

- 封面能否准确承诺文章气质，而非单纯吸睛？
- 第一张内容图是否尽早提供价值？
- 最复杂的关系是否获得解释图？
- 高密度段落之间是否有合理呼吸？
- 每张图的版权、隐私和生成属性是否清楚？
- 删除任意一张图后，文章是否反而更好？如果是，删除它。
