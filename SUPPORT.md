# Support

Use [GitHub Issues](https://github.com/cixiangtao/skills/issues) for reproducible problems with the public skills, broken references, unclear execution boundaries, and focused improvement requests.

Include the skill name, agent or tool, relevant version, invocation, expected behavior, actual behavior, and sanitized evidence. Do not include credentials, private URLs, proprietary source, or machine-specific agent state.

Support for third-party agents and skill installers is best effort. Report vulnerabilities privately through [SECURITY.md](SECURITY.md).
